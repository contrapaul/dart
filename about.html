What DART is

DART is a first person shooter that runs in a web browser. You fight Foamers, monsters from the Foam dimension, with toy foam dart blasters, a shield and a melee. Nothing bleeds: everything that breaks, breaks into foam, and the walls and the Foamers come apart where you hit them. It is free, needs no install or account, and is made for players aged 10 and up.

How it was made

Paul writes the game: the blasters, the Foamers, the story, the names and the levels. The code was written by AI models working from Paul's plan, a single planning document that splits the work into small task cards. Each card names the files it may touch and what "done" means, and code from one model is reviewed by another before it ships.

Work started on 30 October 2026. Since then the project has grown to over 900 commits and more than 1,700 automated tests, which run on every change before it goes live.

The models and machines

Claude (Opus 5.5, with Fable 5.2 for some editor work) led the build: it wrote the plan's task cards, built the harder parts, merged everyone's work and checked it in a browser. Other models built cards in parallel through the Pi coding agent: DeepSeek V4.1 Flash over OpenRouter, Qwen 3.8 running on a local machine, and Inkling 2 Mini running on a DGX Spark and on two V100 graphics cards. Up to six Inkling sessions worked at once on the Spark, each on its own card in its own copy of the code, while the V100s drafted plans and reviewed the results.

Built with

TypeScript, Three.js for the 3D, Rapier for the physics and Vite to bundle it. Every font, model, texture and sound ships with the game: nothing is loaded from another site, so it works on school and venue wifi.

The Map Builder

The same tools that make the game's levels are in the menu: build a level, play it straight away, and find it on the Levels page with its picture and your name as the author.
