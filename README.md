# DART

A browser first person shooter. Foam dart blasters against Foamers, monsters
from the Foam dimension. No blood, no gore: everything breaks into foam.

Play: https://dart.contrapaul.com (in development)

- `PLAN.md`: the design and build plan
- `HANDOFF.md`: where the build stands
- `CLAUDE.md`: rules for anyone, human or AI, working in this repo

## Run locally

```bash
npm install
npm run dev
```

Built with Three.js and Rapier, with AI coding agents. Code is MIT licensed.
