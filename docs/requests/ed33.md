# Requests from ED-33, physics objects

## ED-31: register the physics objects for a move trigger

ED-31's move registry does not exist in this worktree yet, so nothing calls
it. `PhysicsObjects` (src/level/physics-objects.ts) already has:

- `moveBy(id: string, offset: THREE.Vector3)`: shifts the body and wakes it.
  A moved physics object keeps its collider, so a trigger's `move` on one
  works with this call.

What it does not have is a turn about Y. A move trigger that turns a physics
object also needs the body's rotation composed, which belongs to whoever
writes the registry (one call, or a `turnBy(id, degrees)` added here if the
lead prefers). The page builds the system in `src/arena/extras.ts`.

## For the lead: the barrels' blast hook and the profile name

Not ED-33's change and not touched: `src/arena/extras.ts` passes the
ExplosionSystem's second `onBlast` argument (a profile name in
src/weapons/explosion.ts) to `Barrels.onBlast(point, reach)`, which treats
it as metres. The physics objects' own hook reads the profile properly
(`PhysicsObjects.blast(point, profile)`). Worth a look when ED-33's lines are
merged.
