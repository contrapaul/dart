# Requests for the lead

## r3-06: game-side look wiring

The editor view gets the full look (tone mapping, exposure, PMREM sky
light, bounce colour, in `src/editor/view.ts` `refreshLights`), and
`src/level/lights.ts` resolves bounce for every caller. The browser game
(`src/arena/extras.ts` `buildArena`) cannot get the desktop-side part: it
receives only `{ rapier, world, scene, mesherPool }` (see
`BuildInput` in `src/game/game.ts`), so there is no renderer to hand to
`applyLookToRenderer` / `applyLookEnvironment` from `src/render/look.ts`.

Would help if `BuildInput` carried the renderer (or the arena page called
the two apply functions after building), so the arena plays the same look
the editor shows. As it stands the arena plays bounce colour only; tone
mapping, exposure and the environment light are missing there.
