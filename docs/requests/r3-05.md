## 2. src/render/surfaces.ts: seam and polish fixes for the nine existing painters

All of these are visual only. Each painter must keep the look and the greys.

### paintConcrete

The 14 blotches are drawn once at `(cx, cy)` with no wrap-around, so a
blotch near an edge is cut off there, and the 2 by 2 sheet shows the cut
as a seam at the tile boundaries (visible at both joins).
Fix: for each blotch, also draw it at (cx - w, cy), (cx + w, cy), (cx, cy - h),
(cx, cy + h) so it wraps. Alternatively keep each blotch fully inside
[r, w - r] x [r, h - r], but that thins the pattern noticeably near the
centre; wrapping is the right fix.

### paintRock

The 40 blobs are cut at the edges, same as concrete. Fix with the same
wrap-around (or the same bounding-box trick, drawing each blob at all
offsets so it wraps).

### paintGrass

The 2600 blades are drawn as short strokes from (x, y) with no wrap, so
blades near an edge are cut there. Fix: when drawing a blade, draw each
segment line at (x + k*w, y + m*h) for k, m in {-1, 0, 1} (same for the
full blade chain) so it wraps. The speckle (`noise`) is fine.

### paintSand

The dune streaks use `period = 40 + rng() * 60`, so the streak does not
repeat across the repeat (256 px): `sin(x / period) * amp` at x=0 and
x=255 differ by up to about one period's worth of phase, and the 2 by 2
sheet shows each streak with a visible step at the boundary. Fix: replace
the streak shape `cy + Math.sin(x / period) * amp` with
`cy + Math.sin((x / w) * 2 * Math.PI * Math.max(1, Math.round(w / period))) * amp`
(i.e. period divides w), and draw the streak at x and x + w if it is near
the right edge. The sparse dark flecks are fine.

### paintPlanks

The grain `Math.sin((x + row * 37) / 9)` has period 9 * 2 * Math.PI ~=
56.6 px, which does not divide 256, so the grain visibly steps at the
vertical boundary of each tile. Fix: replace both the argument and the
phase with something periodic:
`Math.sin((x / w) * 2 * Math.PI * Math.max(2, Math.round(w / 56)) + phase)`
where `phase = (row * 37) / 9` is dropped (a per-row constant is not
needed) and is replaced by a per-row `phase` from `rng()`. The plank
gap and the nail are already periodic (they are drawn at multiples of 32
and at 18 / w - 18, both inside the full width).

### paintTiles

No structural fix needed (it tiles). Optional polish only, not required:
the bevel-darkening pass `min(..., 150)` at the top edge of each tile can
make the bevel read as an extra dark line at the tile joins on seams;
none of this needs to change to ship the new surfaces.

### paintBrick, paintMetal, paintStripes, paintPlanks (besides the grain)

These three (brick, metal, stripes) already tile and read well on the
sheet. No fix needed. If the lead wants, they can get the same
wrap-around treatment as concrete/rock for future use, but that is not
required for this round.

### paintConcrete contrast (optional)

The 185 base with 0.82-multiplier blotches reads flat once tinted. If the
lead wants a slightly stronger contrast, draw the blotches at 0.78
instead of 0.82. Not required.
