## What to build, in stages (commit each)

1. **Box select.** A left drag that starts on empty space or on a thing
   that is not selected and cannot be dragged (a shape) draws a
   rectangle; on release everything whose centre is inside it is
   selected. Shift adds. Dragging a selected thing still moves it, and
   Alt + drag still orbits. Hidden and eye-hidden things are skipped.
2. **Copy and paste.** Ctrl+C puts the selection on the system clipboard
   as JSON text with a `dart-clip` marker and a version. Ctrl+V reads it,
   gives every entry a new id, and places the set under the cursor (or in
   front of the camera when the cursor is off the view), keeping the
   things' places relative to each other, snapped to the grid. Triggers
   in the selection are copied too, and the ids they name are rewritten
   to the new copies when those were copied with them. One undo step. The
   caps hold: a paste that would pass one is refused with the reason. A
   clipboard that is not a `dart-clip` is ignored. Ctrl+X is copy then
   delete. The start and the exit are never copied.
3. **Groups.** Ctrl+G gives the selected things one shared `group` id (a
   new optional string on each entry in the level file); Ctrl+Shift+G
   clears it. Clicking one member selects the whole group; a double click
   selects only that member. Duplicate and paste give the copies a new
   group id. The game ignores the field. Old levels load unchanged.

## What changed while building (2026-11-16)

- Built in the `ed-12` worktree on top of ED-12, not on its own branch,
  because ED-12 was not committed yet and both edit `main.ts`.
- Copy, cut and paste use the browser's `copy`, `cut` and `paste` events,
  not `navigator.clipboard`, so no permission prompt is needed.
- The paste's move is snapped, not each thing's place, so things that
  were off the grid keep their spacing.
- A box select and a drag also take whole groups. The outliner still
  picks one row at a time, which is the way into a group besides the
  double click.
- `src/editor/view.ts` gained `screenPoints`, and `src/level/validate.ts`
  a rule that a group is a name.
