## Result

Built, one commit per step, on branch swarm/r3-07.

1. `data/arena-templates/{square-room,ring,long-hall,open-yard}.json`: four
   asset files, each an `dart-assets` file with one template. Each is a
   floor, four walls with two door gaps (south and north), cover (two low
   boxes, a staggered column row, a central block and two side covers, or
   five low boxes), a zone over the floor, four spawn points and the three
   fight triggers `buildArena` would write for a two wave fight of F01
   (count 3) then F02 (count 2): enter the zone shows the hidden blocker
   and spawns wave 1, wave 1 all dead spawns wave 2, both waves dead hides
   the blocker. Labels describe the shape; the `_note` in each file is the
   [Paul] placeholder, and each label is named to be Paul's to rename.
2. `src/editor/arena-templates.ts`: `TEMPLATES` reads every file with
   Vite's `import.meta.glob` (eager) and checks each with the asset reader
   (`readAssetsFile`); a broken file lands in `TEMPLATE_ERRORS` and is
   left out of the list. `tests/editor/arena-templates.test.ts` checks
   every template places into a fresh level (via `pasteClip` + `addMixed`,
   the same path the panel uses) and passes `validateLevel` with no
   errors, that ids are renamed on paste, and that no file errors.
3. `src/editor/asset-panel.ts`: the Assets dialog now renders a "Templates"
   section above the saved assets: each template shows its name and a
   Place button that arms it via `armAsset` (the same `host.place` path as
   saved assets; the ghost builds from the clip's prims and markers).
   `src/editor/help.ts` gained a "Templates" row. `editor.css` is not my
   file, so the section renders unstyled; see docs/requests/r3-07.md.

Verified with `.swarm/preflight.sh` (tsc, vitest, dash check) green before
every commit.
