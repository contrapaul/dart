## What to build, in stages (commit each)

1. **Primitives.** `src/level/prims.ts` builds `level.prims`: the mesh from
   `primGeometry`, placed with `primMatrix`, colour from `prim.colour`
   (matte, `MeshStandardMaterial` roughness 0.9 like the shell); fixed
   colliders from `primColliderParts` (cuboid or convex hull, transformed by
   the prim's matrix). `solid` and `breakable` collide (breakable is a
   solid for now, ED-06 makes it break); `decor` is drawn with no collider;
   `hazard` prims are skipped (ED-03 owns them). Shown prims that never
   hide and share a colour are merged into one mesh per colour (draw
   calls). A prim with `hidden: true` is its own mesh and collider, made
   but not shown and with its collider disabled; `BuiltLevel` gains
   `prims: Map<string, { setShown(shown: boolean): void }>` for every
   hidden prim (a trigger shows and hides them later). The nav grid's
   bounds include the prims.
2. **Sky.** `src/render/sky.ts`: `applySky(scene, sky)`. A `gradient` is a
   big inside-out sphere (or a background shader) with the three colours,
   top, horizon, bottom; an `image` loads the data: URL into a texture,
   equirectangular, as `scene.background`. No sky: the scene stays as
   today. The default gradient is `data/editor.json` `sky`.
3. **Placed Foamers.** `level.foamers` spawn when the level loads (and on
   every restart, like the pickups), standing at `pos` facing `yaw`, using
   the same spawn path the arena waves use. `wake: "sight"` Foamers start
   their normal brain when they see the player (find how a brain idles or
   aggroes; if there is no idle state, the smallest addition is a
   per-Foamer "asleep until in line of sight within N metres" check, with N
   in `data/ai.json`). `wake: "trigger"` and `hidden` ones wait: export a
   `wakeFoamers(ids)` on the page side for ED-07's trigger runner.
4. **Doors.** `level.doors` are built like arena doors (same look, same
   slide), `lock: "none"` open, the others shut; add them to
   `BuiltLevel.doors` so `setState` works on them too.
5. **Start loadout and stored levels.** Outside the campaign, a level with
   `start` gives the player only those blasters (the first held), those
   hand weapons and that health, using LVL-05's `Loadout.setOwned`.
   `arena.html?level=local:<key>` loads the level from `getLevel(key)` in
   `src/editor/store.ts` (async: load it before the game is built) and
   runs `validateLevel` on it; errors show on the page's status line and
   the level does not start.
