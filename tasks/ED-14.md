## What to build, in stages (commit each)

1. **The maths.** `resizeFace(prim, axis, side, metres, grid)` returns
   the new `pos` and `size`: the dragged face moves by `metres` along the
   prim's own axis, the opposite face stays where it is, the size never
   goes under one grid step, and the result is snapped when snap is on.
   It must hold for a turned prim.
2. **The handles.** In scale mode (R) a single selected prim, zone, door
   or the exit shows six small handles, one on each face, in place of the
   three.js scale handle. Dragging one pushes or pulls that face. The
   mesh follows live. One undo step on release. Several things selected
   keep the three.js handle as today. Handle size is a number in
   `data/editor.json`.
3. **The size label.** While a face is dragged, and while a shape's
   footprint is dragged out when placing, a label by the cursor shows the
   size in metres (for example `6.5 x 3 x 0.5`).
