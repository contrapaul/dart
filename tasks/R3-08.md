## Result

Built and tested headless:

- `src/editor/arena-formulas.ts`: ArenaFormula (name, waves with foamer/count/promoted/holdSeconds/delaySeconds, lockDoors, unlockOnClear), an IndexedDB store of its own (`dart.arena-formulas`), a file format (`{ dart: "dart-arena-formulas", version: 1, formulas }`) with a reader that refuses broken files, caps in `data/editor.json` `arenaFormulas` (max 40). Pure parts tested in `tests/editor/arena-formulas.test.ts` (store, panel and picture paths not testable headless).
- `src/editor/arena-build.ts`: `buildArena` now carries per-wave promoted/holdSeconds/delaySeconds (delay runs the wave through an `after` trigger of the previous wave's start, the same shape arena-to-triggers uses), `lockDoors` (closes the picked doors at the lock) and `unlockOnClear` (default true; false hides the door opens at clear). Tests added in `tests/editor/arena.test.ts`.
- `src/editor/main.ts` Arena dialog: each wave row gains a promoted tick, an hold-seconds field and a delay field; doors stay level specific (ticked list), plus two toggles (lock doors at start, open doors at clear); a Formula row (select of saved formulas, Save as formula, Delete, Export and Import via file). Choosing a formula fills the dialog. `buildArena` uses the dialog's fields, so a formula builds the same triggers every time.
- `data/editor.json` `arenaFormulas: { max: 40 }`; `src/editor/help.ts` and `src/editor/editor.css` updated.

`.swarm/preflight.sh` green before each commit. Not verified: the dialog itself in the browser (waves UI, formula select/save/delete/export/import, IndexedDB store round trip), the delay-through-after triggers firing in play, and the formula round trip through export/import. A person should: press Build an arena, tick a wave with a delay, lock and unlock toggles, save the dialog as a formula, delete and re-pick it, export and import it, and press Build the triggers.
